Rustia and other Luau projects

§Lua and Luau

  • Lua provides functions, tables for storing data, and coroutines that can pause and resume.
  • Luau adds shortcuts like score += 1, continue in loops, and optional type annotations. Rustia runs annotated scripts without a static type check.

Rustia targets standalone Luau 0.709, including its vector and buffer libraries. Roblox services are outside that scope. Tested language features

§What Rustia adds

  • Replay on desktop and in a browser. In deterministic mode, the same script, seed, and inputs produce the same decisions. Watch the native and Wasm race
  • Keep running through a bad edit. Try a new module while the app runs. If installation fails, Rustia restores the previous script state and your app can keep calling the old functions. Hot reload example
  • Give each decision a budget. Limit the work a script can do and the memory Rustia tracks for it. A script can queue changes for Rust and deliver them only when the call succeeds. Runnable example

What we checked
Runs
The language or bytecode the engine executes.
Written in
The implementation language of the engine. Rust bindings can call an engine written in C or C++.
Platforms
Platform evidence comes from CI, release builds or recorded runs. Each badge identifies the environment and links to its evidence. A build confirms compilation. Rustia’s ARM64 mobile checks ran on a physical iPad and an Android 15 emulator. The competitor mobile badges link to simulator and emulator results. The extended competitor coverage lists the versions tested and separates runtime checks, build checks and upstream evidence.
Hot Reload
The app keeps running in each documented reload path.
  • Keeps chosen state. The embedder can carry selected script state across edits, as the Rustia garden does.
  • Fresh module. The replacement starts with new module-local variables.
  • Host-managed state. The host supplies the replacement and decides what to carry forward.
  • Unverified. The sources showed how to run edited code without establishing a reload path.
Replay
Rustia’s recorded deterministic race matched on native and browser Wasm. ruau documents controls for seeds and the clock. Unverified means the reviewed sources did not establish replay support or provide a matching run.

Sources and details · Checked 28 November 2026.

  1. Rustia restores the previous script state when a module install fails. Its deterministic mode reproduces the native run in a browser. ARM64 mobile tests passed on a physical iPad and an Android 15 emulator, with a browser run in iPad Safari. Compiler · Hot reload · Native/Wasm replay · Desktop · Mobile · Safari
  2. luaur 0.1.8 is a Rust port. The host can replace a registered module in the same VM. Native JIT execution is outside this version’s scope. Our luaur 0.1.8 build did not compile on Linux ARM64 or the ARM64 iOS simulator. The published Linux timing is from x86-64. Checksum evidence · Project · Code generation · Desktop CI · Module API
  3. ulua 0.1.7 forks luaur and adds an opt-in native JIT. The host can replace a registered module in the same VM. Our checksum suite passed on Linux ARM64, macOS ARM64, the iOS simulator and the Android emulator. Windows type-checked. We disabled ulua in our browser suite after a startup crash. The project links to its own browser playground. Checksum evidence · Project · JIT · Desktop CI · Module API
  4. ruau 0.3.0 lets the host unload modules and fix the clock, hash seed and random seed. Its docs describe a Wasm clock. Cross-target replay and browser execution are unverified. Our checksum suite passed on macOS ARM64, the iOS simulator and the Android emulator. Checksum evidence · Project · Linux run · Wasm clock · Module API · Seed controls
  5. luau-rs/luau runs new chunks in the same VM and tests browser execution. Native code generation is in development. Our checksum suite ran in Chrome, Firefox and WebKit, on Linux and macOS ARM64, and in the iOS simulator and Android emulator. Windows type-checked. Checksum evidence · Project · Embedding API · Browser CI
  6. mlua binds Rust to upstream C++ Luau and also supports Lua. The host can replace a registered module. CI builds for Emscripten. Bare Wasm needs WASI imports and Wasm exceptions. Our Luau interpreter checks passed on the iOS simulator and Android emulator. The Android build used the NDK C++ runtime. Checksum evidence · Project · JIT · Emscripten · Bare Wasm · Module API
  7. Lune 0.11.1 uses mlua. It can load an edited script or bundle its VM and bytecode into a standalone executable. The released CLI passed our five Luau workload checks on Linux and macOS ARM64. Windows has an upstream release. Checksum evidence · Project · Executable · Desktop releases · Script loading
