Luau, embedded in Rust.

Rustia is a library for adding Luau scripting to Rust applications, from games to developer tools.

Rustia grew out of a game that needed to script character decisions and replay them on desktop and in a browser.

Rustia features

↻Hot reload
Edit Luau without a rebuild. Your app keeps running and can carry state across edits, like the flowers’ positions here. If a reload fails, Rustia can restore the previous script state.
≡Deterministic execution
Replay a run. In deterministic mode, the same script, starting state, seed, and ordered inputs produce matching results on native and WebAssembly. That helps reproduce bugs and keep lockstep multiplayer clients in sync.
🦀Pure Rust runtime
Simplify embedding. Use the same interpreter on desktop and in the browser. Building the runtime requires no C++ toolchain.
ƒRust functions and objects
Let scripts work with your app. Expose the functions and objects they need, and use Serde to read Luau tables into Rust structs.
⏱︎Script execution limits
Keep runaway scripts under control. Set instruction and VM memory budgets so your app can handle a script that exceeds them.
»JIT and AOT research
Keep editing while scripts compile. We’re exploring just-in-time (JIT) compilation in the background during development, and ahead-of-time (AOT) compilation for bundled scripts. Today Rustia interprets Luau bytecode.

Roadmap

«Time-travel debugging
Step back through a recorded Luau run, inspect earlier values, and find the line that last changed a variable.
🎮A Luau layer for Bevy
We’re building a Luau layer on top of Bevy so you can change gameplay while the game runs, without rebuilding the Rust app.
♫Synth in Luau
We’re also having fun with a Luau synth. Write sounds and music in code, then tweak them while you listen.
