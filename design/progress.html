Heap and GC

Standard uses paced gc-arena debt collection, DeterministicSim uses instruction-count full cycles, weak tables are swept, and tables/functions/upvalues/runtime strings/userdata/buffers/vectors plus loaded programs use generation-safe reusable slots. Retained host values are true roots; explicit quiescence reclaims obsolete programs/coroutines and releases spare backing capacity. Exact VM-owned live/reserved accounting, optional peaks, logical-live quotas, forced-collection retry, and atomic catchable OOM are implemented. Cohort safe-memory-588b541 supplies 99 native Linode samples and a wasm32 512 KiB quota/recovery pass.

80% 92% confidence

Future plan: Add deterministic decision reset, O(1) incremental accounting and script counters, broaden mixed-heap pressure coverage, then tune collection intervals.

Tables/metatables

Broad table, metatable, iteration, and stdlib behavior is conformance-covered. Exact OOP candidate ns/unit is 65.959% lower under its accepted Linux protocol; that comparison also includes the weak-table GC-scan correction.

80% 75% confidence

Runtime profiles

LuauCompat, ReproducibleStandard, and DeterministicSim are concrete runtime profiles. LuauCompat selects Luau-style hash iteration; DeterministicSim omits collectgarbage/gcinfo and optional loadstring, registers the os table iff a deterministic clock provider is plugged, admits a stdout sink on any profile, rejects nondeterministic clock providers, deterministically sweeps weak tables, and rejects external-mutable-state/nondeterministic-effect host registrations. Decision-reset behavior is not yet a complete replay ABI.

77% 82% confidence

Future plan: Specify exactly which globals, RNG, fuel, counters, programs, and heap objects reset at a deterministic decision boundary.

Retained handles

Script function and export handles are true collector roots. 88% 90% confidence
