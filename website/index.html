Luau, embedded in Rust.

Rustia runs Luau scripts in Rust applications. Edit the Luau below to change what the garden draws.

Rustia features

Hot reload
Change Luau while your Rust app keeps running. The garden applies edits as you type.
Deterministic execution
In deterministic mode, the same script, seed, and inputs give the same results on native and WebAssembly.
Pure Rust runtime
The Luau interpreter is written in Rust. The same engine runs on desktop and in the browser.
Experimental LLVM compilation
We’re exploring compiling Luau to native code ahead of time.
