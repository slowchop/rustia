Luau, embedded in Rust.

Rustia runs Luau scripts in Rust applications. Edit the Luau below to change what the garden draws.

Rustia features

Hot reload
Try script edits while your Rust app keeps running. If a module fails to install, the app can keep using the previous version.
Deterministic execution
Replay recorded inputs or reproduce a bug in the browser. In deterministic mode, the same script, seed, and inputs give the same results on native and WebAssembly.
Pure Rust runtime
Embed the same Luau interpreter on desktop and in the browser. Building the runtime requires no C++ toolchain.
Rust functions and objects
Expose the functions and objects your scripts need. Use Serde to read Luau tables into Rust structs.
Script execution limits
Set a budget for instructions and VM memory so a runaway script returns an error to your app.
Experimental LLVM compilation
We’re exploring compiling Luau to native code ahead of time to reduce the cost of running scripts.
