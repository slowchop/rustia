Luau, embedded in Rust.

Rustia runs Luau scripts in Rust applications. Edit the Luau below to change what the garden draws.

Rustia features

↻Hot reload
Keep testing while your app runs. Try Luau changes live. If a module fails to install, the app can keep using the previous version.
≡Deterministic execution
Replay a session or reproduce a bug. In deterministic mode, the same script, seed, and inputs give the same results on native and WebAssembly.
🦀Pure Rust runtime
Simplify embedding. Use the same interpreter on desktop and in the browser. Building the runtime requires no C++ toolchain.
↔Rust functions and objects
Let scripts work with your app. Expose the functions and objects they need, and use Serde to read Luau tables into Rust structs.
⏱︎Script execution limits
Keep runaway scripts under control. Set instruction and VM memory budgets so your app can handle a script that exceeds them.
»Experimental LLVM compilation
Explore faster execution for hot code. We’re experimenting with compiling Luau to native code ahead of time.
