# Security policy

Rustia is an experimental source release. There are no supported package releases
or promised response times.

To report a suspected vulnerability privately, open the repository’s **Security**
tab and choose **Report a vulnerability**. Include the affected revision, embedding
configuration and observed behavior. Omit credentials and private host details.

[Open GitHub’s private reporting form](https://github.com/slowchop/rustia/security/advisories/new).

GitHub makes this route available after the repository becomes public and private
vulnerability reporting is enabled. If the form is unavailable, keep the report
private and retry after activation. Keep vulnerability details out of issues,
pull requests and public discussions.
