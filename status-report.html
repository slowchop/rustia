Objective And Boundaries

Implementation goal

Build rustia as a conformance-first, from-scratch Luau interpreter in Rust, replacing koto only when full Luau parity and deterministic behavior are proven. The current main path is P1 engine core: lexer, parser, compiler, bytecode VM, public API, CLI, and conformance runner.

Locked constraints

The design is locked. Value remains a sealed newtype until the JSC/Firefox wasm gate is measured. Private ops and infrastructure notes stay under private/. Public files may only mention the benchmark runner by the generic target label [self-hosted, bench].
